Drishti Web Guard

Options

Drishti server

The extension only ever calls this server. Default is the local Drishti backend. Changing this to a non-localhost host may require granting a matching host permission (see README).

Account

The analyzer requires a signed-in Drishti user. Access tokens expire in ~15 minutes; the extension refreshes them automatically. Tokens are stored in extension-local storage.

Protection

"Proceed anyway" trusts a hostname for the current browser session. Clearing the allowlist makes those sites prompt again.
